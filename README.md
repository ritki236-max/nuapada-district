# Nuapada District, Odisha — one-page information website

A single self-contained page covering the whole district:

- Interactive 3D map — five blocks + Jonk tehsil, 678 villages, towns and the tour route.
- Blocks section with headquarters and village counts.
- Searchable table of all 678 villages with block and coordinates (click a row to locate it).
- The full 14-stop district tour route with leg distances and a GPX download.
- Key facts: area, population, tehsils, NACs, Gram Panchayats, PIN, constituencies and more.

Sources: map data (c) OpenStreetMap contributors (ODbL); village points from GeoNames (CC BY 4.0);
district facts from the Census of India 2011 and the Nuapada district administration.
